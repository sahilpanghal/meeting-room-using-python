💡 How This Internet Calling System Works

1. Python Signaling Server

Runs asynchronously on your Mac or cloud, managing room membership and securely relaying WebRTC handshake data (SDP offers/answers and ICE network candidates).

2. Direct Peer-to-Peer Audio

Voice streams travel directly between devices using WebRTC (UDP/SRTP) encrypted end-to-end, with ultra-low latency.

3. STUN NAT Traversal

Public STUN servers discover public IPs and ports so calls work seamlessly across different home routers, mobile data, and Wi-Fi networks.
